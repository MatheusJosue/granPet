# 🐶 GranPet

> Site institucional de um pet shop de banho e tosa, com tabela de preços interativa e contato direto pelo WhatsApp.

🔗 **Site:** https://gran-pet.vercel.app

## ✨ Funcionalidades

- Páginas de **início, serviços, sobre e contato**
- **Tabela de preços interativa** por serviço e faixa de peso do pet
- **Botão de WhatsApp** para agendamento
- **SEO** com sitemap e robots gerados pelo Next.js
- Animações com Framer Motion e layout responsivo

## 🛠️ Tecnologias

Next.js · React · TypeScript · Tailwind CSS · Framer Motion · React Icons

## 🧠 Decisões técnicas

- **Preços e dados do negócio em arquivos de configuração** (`lib/`), para atualizar valores sem mexer nos componentes.
- **Componentes de seção reutilizáveis** (hero, chamada para ação, destaques) para montar páginas novas rapidamente.

## ▶️ Como rodar

```bash
npm install
npm run dev
```
